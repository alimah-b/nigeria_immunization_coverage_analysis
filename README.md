## Project Overview
This project analyses the routine immunization coverage in Nigeria from 2015-2025, with a focus on program performance coverage gaps, vaccine dropout rates, key performance indicators and recovery following the COVID-19 disruption period.
The analysis was developed using Microsoft Excel to demonstrate practical skills in data visualization and evidence-based interpretation.

## Objectives
The analysis aims to:
- Assess trends in DTP1, DTP3, MCV1 and MCV2 coverage from 2015-2025
- Identify gaps between initial and subsequent vaccine doses.
- Calculate DTP1-DTP3 and MCV1-MCV2 dropout rates.
- Compare key immunization performance indicators between 2024 and 2025.
- Identify areas of recovery and persistent performance gaps
- Generate insights and recommendations.

## Key Indicators
The analysis focuses on:
- DTP1 coverage
- DTP3 coverage
- MCV1 coverage
- MCV2 coverage
- DTP1-DTP3 coverage gap
- MCV1-MCV2 coverage gap
- DTP1-DTP3 dropout rate
- MCV1-MCV2 dropout rate

## Key Findings
1. Coverage declined across all four core indicators between 2019 and 2021, with MCV2 experiencing the largest decline (4.66 percentage points.
2. Coverage improved across all four indicators between 2021 and 2025, although 2025 levels remained below 2019 levels.
3. In 2025, MCV1-MCV2 dropout (7.67%) was higher than DTP1-DTP3 dropout (5.08%), indicating a larger completion gap for the second measles-containing vacine dose.
4. In 2025, MCV2 remained 2.43 percentage points below its 2019 coverage level in 2025, suggesting incomplete recovery and an area for further programme investigation.
